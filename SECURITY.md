# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately using
[GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
(Security tab → "Report a vulnerability") rather than opening a public issue.

We'll acknowledge reports as soon as possible and coordinate disclosure once a fix is available.

## Supported Versions

Only the latest published release is actively supported.
